# Scientific Calculator Project

This is a C++ command-line application that acts as a scientific calculator. 
I built this project to handle both basic math operations and advanced scientific functions directly in the terminal.

## Features Included
* Basic math: Addition, subtraction, multiplication, and division.
* Scientific functions: Trigonometry (sin, cos, tan), square roots, exponents/powers, and logarithms.
* Simple text-based user interface with a menu.

## How to Compile and Run
To run this program, you need a standard C++ compiler installed on your system.

1. Open your terminal in the project directory.
2. Compile the source file by running:
   g++ "Scientific Calculator.cpp" -o calculator
3. Execute the program:
   ./calculator

## How It Works
When you run the program, a menu will appear on the screen asking you to select an operation.
After choosing an option by entering the corresponding number, the program will prompt you to type in your input values and will then display the final calculated result.
